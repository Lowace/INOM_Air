======================================================================
               INOM AIR - PRESENTATION & DEFENSE EMERGENCY TOOLS
======================================================================

If you run into issues on presentation day, these 4 1-click tools will
save you in seconds:

1. emergency_fix_ports.bat
   - Kills any background or zombie process holding Port 3306 or Port 80.
   - Clears port conflicts so XAMPP MySQL and Apache can start cleanly.

2. start_standalone_mysql.bat
   - Starts the MySQL database engine directly in a console window.
   - Use this if the XAMPP Control Panel GUI freezes, crashes, or refuses to open.

3. test_database_connection.bat
   - Tests if MySQL is online and prints all table row counts (users, aircrafts,
     pilots, flights, bookings) in Command Prompt.
   - You can show this directly to your panel/instructor to prove the database
     is live and working without needing Apache or phpMyAdmin!

4. backup_current_database.bat
   - 1-click snapshot exporter using mysqldump.
   - Saves your current live MySQL database (with all your real bookings,
     customers, aircrafts, and flights) into a safe backup file.

5. restore_database.bat
   - 1-click import to restore your database back to MySQL if it gets
     accidentally deleted or corrupted.
